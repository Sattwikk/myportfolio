My Projects

Welcome to my project portfolio. These projects represent my experience with programming, mobile application development, databases, and practical software engineering.

Through these projects, I have focused on creating functional applications while strengthening my problem-solving and development skills.

Rocket Launch Controller

The Rocket Launch Controller project focuses on building an application that manages and monitors a simulated rocket launch process.

The project helped me practice application logic, user interaction, and structured software development while working with Flutter.

Digital Pet App

The Digital Pet App is a mobile application designed around caring for and interacting with a virtual pet.

I used Flutter to develop the application and practiced organizing the project into reusable components while creating an interactive user experience.

Inventory Management App

The Inventory Management App is a mobile application for creating, viewing, updating, and managing inventory records.

The project uses Flutter and Firebase to work with application data and demonstrates CRUD operations, validation, and real-time data updates.
